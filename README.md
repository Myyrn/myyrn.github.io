# Elental — runnable skeleton (spec: `*__spec.md`)

Plain JS + ES modules, no bundler. `npm test` runs 103 tests with Node's built-in runner (Node >= 20).

## Launch
Hosting target is GitHub Pages: everything is static files; the simulation engine runs in the browser (main thread). `serve.py` is only a local convenience.
```
python3 serve.py            # then open http://localhost:8000/   (any static server works; file:// does not, because of fetch)
node tools/headless.mjs demo 20     # same engine, no browser: 20 turns, one summary line per turn
npm run build:data          # regenerates data/ruleset.json and scenarios/demo/*.json
```
**Editor**: open `http://localhost:8000/editor.html` — edit the demo or a blank scenario (map tools, tables, generators, validation, headless playtest), then *Launch in game*.
The browser shell (`index.html`, `src/ui/debugShell.js`) is a **debug shell**, not the game UI: hex map with lenses, selected-province card, cell table,
Government card, an Orders tray (setTaxLaw, placeRequisition, setControlAllocation go through the real Action pipeline), End Turn / Run 10, history table.
It has not been exercised in a real browser yet (only syntax-checked and served over HTTP); the engine behind it is covered by the tests.
